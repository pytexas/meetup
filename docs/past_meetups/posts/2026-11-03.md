# November 2026 Meetup

Security problems rarely begin as security problems. They often begin as unclear assumptions, missing boundaries, rushed integrations, or decisions made before risks are visible. As Python becomes a common foundation for AI-enabled applications, teams need practical ways to bring security thinking earlier into design conversations. This talk introduces threat modeling as a lightweight habit for Python teams building AI, data, and cloud-connected systems. Pavan explains how to frame risks around data flow, identity, model behavior, user interaction, third-party dependencies, and operational responsibility. The session avoids technical exploits and instead focuses on collaboration patterns that help developers, security teams, and product stakeholders reason together. Attendees leave with a clear mental model for asking better questions, identifying architectural weak points, and making security a shared design responsibility.
